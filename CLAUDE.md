## Project Overview

**sanskrit-fonts** hosts web fonts used for displaying Sanskrit text in the Cologne Digital Sanskrit Lexicon web interface and related tools.

## Contents

| File | Purpose |
|---|---|
| `siddhanta.ttf` | Siddhanta OpenType font for Devanagari Unicode rendering, created by Міхаіл Баярын |

### License

### Usage

The font is referenced in CDSL web displays (e.g., `csl-apidev/css/basic.css`) to render Devanagari text with correct glyph shaping. It is also included in StarDict packages built by `cologne-stardict`.
